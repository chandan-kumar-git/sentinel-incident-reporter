# **App Name**: Sentinel AI: Cyber Incident Reporter

## Core Features:

- Incident Submission: Allows Indian Defence personnel to submit cyber incidents (URLs, text, files) via a web form.
- Mock AI Analysis: Simulates AI analysis of submitted content, assigning a risk level based on keywords and content type, acting as a reasoning tool.
- Risk Level Assessment: Assigns a risk level (Low, Medium, High, Critical) to each incident based on the AI analysis.
- Mitigation Steps Generation: Generates recommended mitigation steps based on the assessed risk level using mock analysis.
- Submission Confirmation & Alert: Displays a confirmation page with the incident details, risk level (color-coded), and recommended actions.
- CERT-Army Dashboard: Presents a dashboard for CERT-Army personnel to view and triage incidents, including summary statistics and a sortable incident table.
- Incident Details View: Provides a detailed view of individual incident reports.

## Style Guidelines:

- Primary color: Dark navy blue (#2E4053) to convey security and professionalism.
- Background color: Light gray (#F5F5F5) for a clean and minimalist aesthetic.
- Accent color: Orange-red (#E53935) for critical alerts and important actions, indicating urgency.
- Body and headline font: 'Inter', a sans-serif font, for a modern, clean, objective look appropriate for both headlines and body text.
- Use simple, geometric icons to represent incident types and risk levels.
- Maintain a clean, minimalist layout with ample whitespace to ensure readability and reduce visual clutter.
- Use subtle animations for loading states and transitions to enhance user experience.
